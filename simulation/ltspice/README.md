# LTSpice Circuit Simulations

This directory contains circuit simulations performed during the development of the custom Analog Front End (AFE) for the CGM prototype.

## Simulation Objectives

- Evaluate Transimpedance Amplifier (TIA) circuit behaviour.
- Study conversion of low-level sensor current into voltage.
- Analyze amplifier gain and output response.
- Investigate feedback resistor selection.
- Evaluate circuit response under different input conditions.

## Tools

- LTSpice
- Operational amplifier models
- Custom analog circuit configurations

## Files

Contains LTSpice schematics, simulation models and relevant circuit analysis files.

## Note

Simulation results represent circuit-level analysis and may differ from actual hardware measurements.
